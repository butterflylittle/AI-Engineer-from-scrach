Agentic RAG 检索图

路由先判断是否需要检索；检索链路 retrieve → rerank → grade；证据不足时 rewrite 改写查询后重试，最多 max_rewrite_rounds 轮。问候语直答分支绕过检索。

flowchart LR
    START([START]) --> route{route<br/>意图路由}
    route -- "需要检索" --> retrieve[retrieve<br/>向量检索]
    route -- "问候直答" --> generate[generate<br/>生成回答]
    retrieve --> rerank[rerank<br/>重排序]
    rerank --> grade{grade<br/>相关性评分}
    grade -- "证据充分 / 轮次已满" --> generate
    grade -- "证据不足" --> rewrite[rewrite<br/>查询改写]
    rewrite -- "重写后重试" --> retrieve
    generate --> END([END])

graph.py 的 build_graph() 编译出的状态图：六个节点 + 两个条件分支 + 一个改写重试环。

检索主链路（route → retrieve → rerank → grade → generate）
改写重试环（grade → rewrite → retrieve）
问候直答分支（route → generate，绕过检索）

各节点写入 RagState 的字段

routerequires_retrieval: bool
retrieveretrieved_documents
rerankreranked_documents
gradeevidence_sufficient: bool
rewriterewritten_query · rewrite_rounds +1
generateanswer · citations

两个阈值来自配置：grade 用 relevance_threshold 判断首条重排结果是否足够相关；after_grade 在证据充分或 rewrite_rounds ≥ max_rewrite_rounds 时终止循环。
